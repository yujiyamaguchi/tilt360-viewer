# Tilt 360 Viewer

360°回転する動画（被写体のまわりをカメラが1周する動画）を選ぶと、スマホの傾きに合わせて回して見られるビューアです。

**https://yujiyamaguchi.github.io/tilt360-viewer/**

- 動画は端末の中だけで処理します。どこにも送信しません（CSP で外部との通信を禁止しています）
- 一度開けば、オフラインでも使えます
- Android（Chrome）/ iPhone（Safari）: 画面を1回タップすると傾きセンサーが有効になります。PC ではドラッグで回せます
- 動画の全フレームをそのまま1周として使います。最後のフレームの次に最初のフレームが自然につながる動画を選んでください
- 逆向きに回るときは「回転方向」で切り替えます

AI 生成のオービット動画（MiniMax H3 + 360° Orbit LoRA など）を見るために作りました。このリポジトリにはビューアのコードだけが入っていて、モデルや動画は含みません。
